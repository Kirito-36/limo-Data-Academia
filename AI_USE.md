# AI Use

## AI Tools Used

The team may use AI tools as supplementary tools during the development
of the LIMO processor project.

Tools used may include:

- ChatGPT
- Claude
- Copilot

## Purpose of AI Use

AI tools may be used for:

- Understanding technical concepts
- Explaining programming concepts
- Debugging assistance
- Generating ideas for testing
- Identifying possible implementation issues
- Improving documentation and explanations

## Verification

All AI-assisted work is reviewed and verified by the team before being
included in the project.

Team members are responsible for understanding the code and technical
decisions included in their contributions.

## Individual Contributions

AI-assisted contributions remain the responsibility of the team member
who submits them. Each member must be able to explain their own work
during project reviews and oral defences.
