## Repository Structure

- `src/` – LIMO source code
- `tests/` – tests and test cases
- `examples/` – example LIMO programs
- `docs/` – ISA specification, design documents, and test reports
- `AI_USE.md` – documentation of AI tool usage

## Development Workflow

The `main` branch is protected.

All development is performed on feature branches and submitted through
Pull Requests. Pull Requests must be reviewed by another team member before
being merged into `main`.

## Contribution

Each team member contributes using their own GitHub account. Commits and Pull
Requests are used to track individual contributions.
